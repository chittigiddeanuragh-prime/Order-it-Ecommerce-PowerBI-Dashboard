An interactive Power BI analytics dashboard designed to analyze grocery e-commerce and delivery performance across sales, products, outlets, ratings, and customer-facing business metrics.

1. Project Title / Headline
🛒 OrderIt — E-Commerce & Delivery Analytics Dashboard

A dynamic and interactive Power BI dashboard that transforms grocery sales data into actionable business insights through KPI cards, interactive filters, product analysis, outlet performance visualizations, and sales trend analysis.

2. Short Description / Purpose

OrderIt is an interactive Power BI dashboard built to analyze and understand e-commerce grocery sales and outlet performance.

The dashboard helps users explore key business metrics such as total sales, average sales, number of items, average ratings, outlet performance, product categories, fat content, outlet size, location type, and sales trends over time.

The goal is to turn raw transactional data into an intuitive analytical workspace that can support business decision-making, sales analysis, product strategy, and outlet optimization.

3. Tech Stack

The dashboard was developed using the following technologies and tools:

📊 Power BI Desktop — Main platform used to design and build the interactive dashboard.
🔄 Power Query — Used for data cleaning, transformation, and preparation.
🧠 DAX (Data Analysis Expressions) — Used to create calculated measures including Total Sales, Average Sales, Average Rating, and other analytical metrics.
🗂️ Data Modeling — Used to organize the dataset and connect fields required for interactive analysis.
🎛️ Slicers & Filters — Used for dynamic filtering based on outlet location, outlet size, item type, and analytical metrics.
🔖 Bookmarks & Navigation — Used to improve dashboard navigation and user interaction.
🎨 Power BI Visuals — Cards, donut charts, bar charts, line charts, funnel charts, tables/matrices, slicers, and custom dashboard elements.
📁 File Format — .pbix for the Power BI development file and .png for dashboard previews.

5. Features / Highlights
💼 Business Problem

E-commerce and grocery businesses generate large amounts of sales and product data across multiple outlets and product categories.

However, raw datasets make it difficult to quickly answer questions such as:

Which products generate the highest sales?
Which outlet types perform better?
How does outlet size affect sales?
Which item categories contribute the most revenue?
How do sales change based on outlet establishment year?
Which fat-content category contributes more to sales?
How do different outlet locations compare?
What are the overall sales and product performance metrics?

OrderIt addresses these challenges by presenting the information through an interactive analytical dashboard.

🎯 Goal of the Dashboard

The primary goal is to provide a centralized analytics workspace that:

Enables quick monitoring of key business KPIs.
Helps compare outlet performance.
Identifies high-performing product categories.
Analyzes sales distribution by fat content and outlet size.
Tracks sales trends across outlet establishment years.
Allows users to dynamically filter and explore the dataset.
Converts raw grocery data into easy-to-understand business insights.
